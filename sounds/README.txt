Put your sound files (.mp3, .wav or .ogg) in THIS folder.

WoW addons cannot list folder contents, so after dropping a file here you
must tell the addon its name once: open the game, type /tsfx, pick an event
and add the file name (for example: kill1.mp3).

If a sound does not play, use the Test button next to it in the options:
 - check the spelling and the extension (.mp3 / .wav / .ogg)
 - make sure the file really is in this folder
 - .ogg files only work on modern clients (WoW Forever, retail); use .mp3
   or .wav for maximum compatibility
